We compute fair value before Kalshi does.

Probabilistic weather forecasting mapped to Kalshi contract pricing: we turn ensemble distributions into fair values for each contract before the market does.

View on GitHub How it works →

How it works

01

Pull NWS ensemble forecast for Austin, TX

02

Fit a normal distribution — estimate mu and sigma

03

Use normal CDF to compute fair value for each Kalshi contract

04

Market-make around fair value with passive limit orders
